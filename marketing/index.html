Memory composes in five layers

Each layer has its own writer, its own cadence, its own kind of truth. None can collapse into the others without losing what makes a mind a mind.

L5

Reflection

Reflexion at session-end with four fan-out writers (memory, skill drafts, persona observations, Honcho updates). Founder-gated; nothing auto-applies.

L4

Procedural

Skills, persona files, hard rules. Voyager-style skill compilation: patterns recur, become candidates, you approve with a single reaction.

L3

Episodic

Cosine recall over local Xenova embeddings (384-dim, ~50ms/encode, $0/encode). Top-3 related episodes inject as context on every new thread.

L2

Identity

Theory-of-mind on each peer via Honcho. Workspace · Peer · Session · Message — relational facts that evolve across all conversations.

L1

Working

Current session state. Auto-managed by the model itself via the CLAUDE.md file pattern.
